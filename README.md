# 知屿写作 Omniisle Write 社区版

简体中文 | [English](README_EN.md)

> 当前目录已通过本机技术门禁，可以作为 GitHub 社区版源码仓库使用。首次公开前仍应由权利人复核提交文件和素材来源记录。

知屿写作（英文名：Omniisle Write）社区版是一套面向中文长篇写作的本地电脑应用。作品保存在当前浏览器中，不要求登录，不连接知屿后端；需要 AI 时，由使用者在设置中填写自己的模型地址、模型名和 API Key。

## 社区版、线上版与企业合作

| 版本 | 适合谁 | 提供什么 |
| --- | --- | --- |
| GitHub 社区版 | 愿意自行安装和配置模型的个人用户、开发者 | 本地使用、用户自备 API、不含知屿账号和云服务 |
| 知屿写作线上版 | 希望打开网页直接使用的作者 | 由知屿运营的账号、计费、在线服务和持续维护，与本仓库分开运行 |
| 企业本地部署 | 对稿件保密、多人协作和内部管理有要求的企业 | 根据真实需求评估的企业内部系统，不包含在本仓库中 |

本仓库只提供社区版。线上收费服务不会因为社区版公开而停止；企业合作的含义和边界见 [COMMERCIAL.md](COMMERCIAL.md)。

## 本地启动

需要 Node.js 20 或更高版本。

```bash
npm ci
npm run build
npm run serve
```

浏览器打开终端显示的本机地址。不要直接双击 `index.html`，否则部分浏览器存储和模块加载能力可能不可用。

## 当前包含

- 本地作品、分卷和章节管理
- 正文编辑、自动保存、历史版本和导入导出
- 大纲、记忆库、模板、查找替换和排版工具
- 用户自备 API 的正文生成、改写、润色和全文分析
- 本地检查点与全文分析八份资料保存

## 数据与联网边界

- 作品数据保存在当前浏览器；清理浏览器数据会导致作品丢失，请定期导出备份。
- 默认阻止外部网络请求。首次连接用户填写的模型地址前，会显示目标域名并要求确认。
- API Key 和写作内容只应发送到用户确认的模型地址，不经过知屿服务器。
- 社区版不包含账号、云同步、积分、充值、支付和管理后台。

## 开发检查

```bash
npm test
npm run audit:public
```

`npm test` 检查社区运行包、本机写作边界和全文分析流程。`npm run audit:public` 检查密钥、旧后端、商业实现、额外联网和缺失素材；两项都应在每次公开提交前保持通过。
